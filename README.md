# TS-P73

### Vocal Preamp by thesecondspeaker

**TS-P73** is a free boutique vocal preamp VST3 plugin for macOS, designed to add warm, smooth and musical analog colour to vocals and other audio sources.

Its custom signal path combines transformer-style low-frequency character, Class-A inspired saturation, gentle level-dependent compression and a second soft saturation stage.

The goal is not heavy distortion. TS-P73 is designed to add subtle weight, harmonic richness and preamp character while keeping the source musical.

## Controls

### TONE
Shapes the high-frequency character.

- Left — darker and smoother
- Right — more open and extended

### DRIVE
Controls the amount of preamp colour and saturation.

Lower settings provide subtle transformer and Class-A character. Higher settings introduce additional harmonic colour, saturation and gentle compression.

### OUTPUT
Controls the final output level.

- Centre — 0 dB
- Range — -18 dB to +18 dB
- Fully left — mute

## Signal Character

- Transformer Colour
- Class-A Saturation
- Gentle Compression
- Soft Harmonic Saturation
- Analog-Style Tone Shaping
